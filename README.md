# 摘星计划 SlimStars 🚀

减肥打卡 × 深夜飞控中心。你是自己减肥任务的指挥官：**每晚只录四件遥测**——晚饭几点吃、吃了多少、喝没喝饮料、动没动——然后「点火」执行任务。成功夜会在**星图**上点亮一颗航点，连续的成功夜自动**连线成航线**，从 1 夜一路飞向 730 夜。

> 与 `slim-quest`（糖果消消乐版）是同一核心需求的两个独立创意版本，数据互不相通。

## 玩法

- **今夜**：点选遥测 → 实时判定读数 → 「点火」——小火箭升空 + 星形彩带 + 任务结算。
- **星图**：月历即星图。成功夜 = 亮星（≥6 分 = 四角超新星），偏航 = 红色异常点，连续成功自动连线。点任意日期补录。
- **任务**：航线节点从「首飞」到「双年星际」（1/2/3/4/5 夜、周末双任务、7 夜在轨、14 夜、21 夜、满月 30、百日、周年、双年…），实时显示「还差 N 夜」，另有 22 枚任务徽章。
- **地面站**：任务第 N 天、成功率、连飞纪录、近 14 夜遥测柱、本月星图密度；数据导出/导入 JSON。

## 快速开始

```bash
npm install
npm run dev      # 开发（5189 端口）
npm run build && npm run preview
```

数据在浏览器 localStorage（键 `slim-stars-v1`），无账号无后端。

## 评分规则（UI 内同步展示）

| 维度 | 分值 |
| --- | --- |
| 晚饭时间 | 16点前 +3 · 17点 +2 · 18点 +1 · 19点 0 · 20点后 -2 · 没吃 +3+2 |
| 食量 | 微微吃 +3 · 少吃 +2 · 适中 0 · 多吃 -2 · 很多 -3 · 非常多 -4 |
| 饮料 | 没喝 +1 · 无糖 0 · 含糖小杯 -1 · 大杯 -2 |
| 运动 | 每项 +2，每天封顶 +4 |

≥2 分 = 成功夜（点星），≥6 分 = 完美夜（超新星）。经验与等级同 v1 曲线，职级从「见习乘员」到「传奇航天员」。

## 技术栈

Vite + React 18 + TypeScript + zustand(persist) + framer-motion + canvas-confetti（星形粒子）。字体：ZCOOL XiaoWei（铭牌）+ JetBrains Mono（遥测数据）。图标、机器人阿控、航点全部手绘 SVG。
